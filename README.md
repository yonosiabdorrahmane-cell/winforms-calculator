#C# Windows Forms Calculator



Une application de calculatrice desktop développée en C# avec .NET 8 et Windows Forms dans le cadre de ma formation BTS DAI (Développement d'Applications Informatiques).



## Fonctionnalités

\- Opérations arithmétiques de base (addition, soustraction, multiplication, division).

\- Interface utilisateur intuitive et sécurisée (saisie clavier verrouillée pour éviter les erreurs d'entrée).

\- Gestion propre des erreurs et des exceptions.



\## 🛠️ Technologies \& Outils

\- \*\*Langage :\*\* C# (.NET 8.0)

\- \*\*Framework :\*\* Windows Forms (WinForms)

\- \*\*IDE :\*\* Visual Studio 2022
